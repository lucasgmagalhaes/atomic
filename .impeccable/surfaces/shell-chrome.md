## Direction contract

THESIS: Nimble is not a browser with tabs — it is an apiary: many colonies (profiles) working unattended, each inspected on the keeper's own schedule, not the tool's. Refuses the category default of "tabs in a dark chrome window" and "purple-accent SaaS dashboard cards" — the two ruts every AI-generated tool UI falls into.

OWN-WORLD: Warm, light, inviting — honey amber (#e0a838-ish) as the single committed accent, beeswax cream and warm parchment as light surfaces, deep umber-brown (not black) as the darkest ground. Hexagonal cell motif carries the grid: pane tiles are hex-capped cards, not plain rectangles; workspace rail reads as numbered hive stands. Headings in a warm, characterful slab/serif (Fraunces) paired with a clean grotesk body (Instrument Sans) for small-UI legibility — not Inter, not a generic system sans. Subtle warm paper/wax-grain texture on panels instead of gradient blur or glass. Nothing heavy or industrial — light backgrounds dominate, dark is reserved for emphasis only.

STORY: The keeper (user) checks in on many colonies at once — which are actively foraging (online, doing something), which are resting (idle/throttled), which need attention (reconnecting/error). Task-first (Operate mode): density and at-a-glance state legibility outrank decoration; the honey/hex language is restraint applied consistently, not illustration layered on top.

FIRST VIEWPORT: the pane grid as an apiary yard — each running profile is a hex-capped hive tile with a soft amber glow when active, muted grey-wax when idle; the workspace rail on the left is a column of numbered hive-stand markers; the toolbar reads as a light wooden tool-shelf strip, not a dark command bar. Add-profile reads as "add a colony."

FORM: candidate #1 of the derived seven (apiary), my own top-ranked pick, offered as IMPECCABLE'S PICK against seed key 2d18422a's assigned index 6 (industrial control room) — user chose the pick over the roll.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
